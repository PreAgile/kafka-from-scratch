## 할 것

1. 내 저장소에서 해당 부분이 어떻게 구현되어 있는지 읽어라.
2. 실제 Apache Kafka 가 같은 문제를 어떻게 푸는지 조사하라.
   소스, 공식 문서, 관련 KIP 를 찾아라. 기억에 의존해서 쓰지 말고 실제로 확인하라.
3. 차이를 표로 정리하라. 각 차이에 대해 **왜 Kafka 는 그렇게 했는가** 를 적어라.
   "규모 때문" 같은 뭉뚱그린 답 말고, 어떤 구체적인 요구가 그 설계를 강제했는지.
4. 내 선택이 더 나은 지점이 있으면 그것도 적어라. 학습용이라 단순해도 되는 부분이 있다.
5. Kafka 도 과거에 다르게 했다가 바꾼 이력이 있으면 그 역사를 적어라. 왜 바꿨는지가 가장 좋은 학습 재료다.

## 출력

표 하나 + 표에 안 들어가는 맥락 설명. 출처 링크를 반드시 달아라.
결과를 `docs/notes/` 에 파일로 저장할지 물어라.
