`scripts/codex-review.sh $ARGUMENTS` 를 실행하라.

인자가 없으면 현재 브랜치를 main 과 비교한다. 커밋 전 상태를 보려면 `--uncommitted`,
결과를 PR 에 올리려면 `--post <번호>` 를 붙인다.

## 실행 후 할 것

1. Codex 의 출력을 읽고 반례마다 다음으로 분류하라.
   - **확실히 깨짐**: 코드 근거가 명확한 것
   - **확인 필요**: 그럴듯하지만 실제로 그 순서가 가능한지 검증이 필요한 것
   - **오판**: 코드를 잘못 읽은 것. 어디를 잘못 읽었는지 적어라
2. "확실히 깨짐" 항목은 재현 테스트를 작성해서 실제로 실패하는지 확인하라.
   테스트 작성은 허용된다. 프로덕션 코드 수정은 금지다.
3. 재현되지 않는 반례는 버려라. 분산 시스템 타이밍 문제에서 모델은 실제로는
   일어날 수 없는 시나리오를 그럴듯하게 만든다.
4. Claude 리뷰가 같은 PR 에 이미 달려 있으면 대조하라. **한쪽만 지적한 것 중에
   재현되는 것이 가장 가치 있다.** 양쪽이 같은 것을 지적하면 비슷한 데이터를 봤기
   때문일 수 있다.

## 사용량 주의

ChatGPT 구독 사용량에서 차감된다. 5시간 제한에 걸리면 로컬 Codex 작업 전체가
막히므로, PR 마다 습관적으로 돌리지 말고 불변식이 걸린 변경에만 쓴다.
