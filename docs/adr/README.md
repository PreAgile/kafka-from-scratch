# 설계 결정 기록 (ADR)

구현하면서 내린 선택을 한 장씩 남깁니다. 파일 하나에 결정 하나, 한 장을 넘기지 않습니다.

## 왜 쓰는가

코드는 "무엇을 했는가"만 남기고 "왜 그렇게 했는가"와 "무엇을 포기했는가"는 안 남깁니다. 이 프로젝트에서 진짜 자산은 후자입니다.

특히 **결과** 항목이 중요합니다. 하나의 결정이 다음 결정을 어떻게 강제했는지 적어두면, 이 문서들을 순서대로 읽는 것만으로 Kafka 설계의 인과 사슬이 복원됩니다.
